Questions

Why does my computer warn me about Cue?

Windows and macOS warn about any app that isn’t registered (“signed”) with Microsoft or Apple. Cue is built by Synapse for our own team, so it isn’t registered yet. The warning is about the missing registration, not about anything Cue does.

Is it safe?

Yes. Cue only records the calls you start or allow, and keeps them in a private workspace. Clients only see their own calls. The download is checked against a fingerprint before it’s saved, so a damaged or swapped file is refused.

Do I need to do this again for updates?

No. Cue updates itself. You only see these warnings the first time you install it on a computer.

Who can use it?

Synapse’s team, and people at Synapse’s clients who have been invited. Clients only ever see their own calls; their Synapse team sees them too, so you’re never asked to send notes. To get an invite, ask your Synapse contact.
